# Maxdevwebsite Portfolio

A modern personal portfolio website built with plain HTML, CSS, and JavaScript. The site showcases a developer-focused profile with sections for about, services, resume, featured projects, and contact information.

## Features

- Responsive single-page portfolio layout
- Smooth scrolling navigation and active section highlighting
- Animated hero section with typing effect
- Modern dark UI styling with glowing accents
- Featured project cards with buttons linking to GitHub and live demos
- Browser tab icon using your profile image

## Project Structure

- `index.html` – Main page structure and content
- `style.css` – Complete styling, layout, animations, and responsive design
- `script.js` – Navigation behavior, typing animation, and UI interactions
- `logopic.jpg` – Browser tab icon / profile image asset

## Getting Started

1. Open the project folder in your browser directly, or serve it locally.
2. If you want to run it via a local server, use:

```bash
python3 -m http.server 8000
```

3. Then visit:

```text
http://localhost:8000
```

## Customization

You can update:

- Your name, bio, and social links in `index.html`
- Colors and visual theme in `style.css`
- Interaction behavior in `script.js`
- Project cards and links in the portfolio section inside `index.html`
